# Frontend React Rules

- Reuse existing components, hooks, and state patterns before creating new abstractions.
- Keep UI accessible: keyboard operation, labels, contrast, focus states, and semantic structure.
- Keep component APIs small and typed.
- Avoid layout shifts from dynamic content; use stable dimensions for fixed-format controls.
- Validate responsive behavior for user-facing changes.
- Escalate copy or scope changes to `pm-portfolio`.
